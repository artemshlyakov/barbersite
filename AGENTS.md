# HABIB BARBER — instructions for coding agents

Read README.md and docs/PROJECT.md before changing code.

This is a real client project for one independent barber named Habib. Visual direction: dark, premium, minimalist, warm bronze accents; reference marrielbarber.com (do not copy it). Hero uses the real portrait supplied by the owner (640×640 originally). Site must be mobile-first.

## Roadmap
- V1: one-page static demo; hero, about, services, portfolio, location, contacts, favicon. No database, backend or online booking.
- V2: DIKIDI integration; DIKIDI Business provides one calendar for website and manually entered bookings. Do not build a parallel booking database.
- V3: possible Telegram bot; postponed.

## Strict rules
Do not invent the barber's phone, Telegram, address, prices, experience, testimonials or real portfolio. Clearly mark placeholders. Do not present other people's cuts as Habib's work. Don't push secrets/client data. GH Pages is a temporary design preview only, not commercial production hosting. Do not deploy production without approval.

For each change: test 320, 360, 390, 768 and 1440px; verify a11y and no horizontal overflow; report what is tested and what remains unverified.
