## Реализация

Статические RU/EN страницы с общими CSS и JS. Локальные шрифты Oswald/Manrope и Yandex Static Maps API (изображение с переходом к интерактивной карте). На первом экране — фотография на весь фон, затем портрет и история Хабиба, бежевый прайс, галерея, карта и контакты. Галерея открывается в доступном диалоге; меню, плавные появления и кнопка записи адаптированы для телефона. `prefers-reduced-motion` отключает необязательное движение. Preview остаётся `noindex`; сборка для утверждённого HTTPS-адреса добавляет SEO-метаданные и карту сайта.

## Визуальная система и адаптация

- На широком экране в блоке знакомства портрет Хабиба находится слева, текст и действия справа; на телефоне текст идёт первым, затем компактный портрет. Кадр `assets/habib-detail.webp` получен из фотографии владельца. Рамка и фирменная печать сохраняют акцент, а размер портрета ограничен для спокойного визуального ритма.
- Три действия в блоке знакомства ведут в подтверждённые Telegram, Telegram-канал и на телефон. Их SVG-иконки взяты из Tabler Icons (MIT); атрибуция и лицензия лежат в `README.md` и `assets/icons/TABLER-LICENSE.txt`.
- Кабель гирлянды — неглубокая симметричная дуга SVG; лампочки — готовая иконка Phosphor Icons (MIT). Положения ламп рассчитаны так, чтобы они висели вдоль изгиба. Декоративная гирлянда скрыта от скринридеров.
- Числа в демонстрационном прайсе плавно досчитываются один раз при появлении блока. Итоговые суммы остаются в HTML и показываются сразу без JavaScript или при `prefers-reduced-motion`. Остальные появления сдержанные; для небольшого движения не добавлены сторонние библиотеки.

Для локальной проверки: `python3 -m http.server 4173`, затем открыть `/` и `/en/` на ширинах 320, 390, 768 и 1440 px. `npm run build` собирает папку `dist/` с `noindex`. Перед коммерческой публикацией требуются утверждённые прайс, фотографии работ, точный адрес и решение о домене и SEO-индексации.
