# HABIB BARBER — проект V1

Персональный сайт барбера Хабиба во Владимире. Визуальная основа — макет из архива, предоставленного владельцем. Его тёмная палитра, узкий акцидентный шрифт, бронзовые акценты, композиция с портретом и мобильный CTA сохранены.

## Подтверждённые факты

- Хабиб — барбер во Владимире.
- Телефон: +7 904 033 9177; Telegram: `https://t.me/khabiBarber`; канал: `https://t.me/khabiBarber13`.
- Координаты: 56.145343, 40.421006. Вход рядом с кафе «Юность».
- Портрет 640×640 предоставлен в архиве владельца.

## Пока не подтверждено

Перечень услуг, цены, часы, биография, фотографии работ и точный почтовый адрес. Сайт показывает это явно и не подменяет данные демо-примерами.

## Решения V1

- Статические страницы RU/EN с одинаковой структурой; общего сервера, базы данных и формы записи нет.
- Контактные CTA ведут в Telegram или на `tel:`. Запись согласуется лично.
- В блоке места отображается карта на данных OpenStreetMap с точкой, без рекламного баннера. Она использует локальную копию Leaflet; атрибуция OpenStreetMap остаётся видимой. Ссылка на маршрут в Яндекс Картах доступна рядом.
- Для коммерческого адреса отдельная сборка добавляет canonical, hreflang, Open Graph URL, sitemap и разрешение индексации. Демоверсия закрыта от индексации.
- Шрифты Manrope и Oswald размещены локально, без запроса к Google Fonts при открытии страниц.
