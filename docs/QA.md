# Проверка дизайн-версии

- Chromium, RU/EN: ширины 320, 390, 768 и 1440 px. Нет горизонтального переполнения и ошибок JavaScript.
- Мобильное меню: открытие, закрытие по Escape и клавиатурная навигация. Диалог галереи: открытие, листание стрелками, закрытие по Escape и возврат фокуса.
- Карта Leaflet: тайлы загружаются, маркер присутствует на подтверждённых координатах. Внешние тайлы в облачном тестовом окружении проверены с `ignore_https_errors` из-за сертификата тестового прокси; на целевом домене нужна повторная проверка.
- Телефон и Telegram: ссылки сохранены в обеих версиях. Фото работ и прайс явно обозначены как демонстрационные данные.
- Публичная тестовая сборка `PUBLIC_SITE_URL=https://example.ru npm run build`: canonical, hreflang, sitemap и разрешающий robots. После проверки восстановлена сборка без URL с `noindex` и запретом обхода.
- axe-core на 390 и 1440 px, RU/EN: после исправления контраста нет нарушений WCAG 2 A/AA и 2.1 A/AA.
- Сравнительные скриншоты до/после: `docs/design-review/`.
