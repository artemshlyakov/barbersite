# Проверка концепции HABIB BARBER

Проверено локально в Chromium на ширинах 320, 390, 768 и 1440 px для RU и EN:

- Оба языка загружаются; изображения, CSS, JavaScript и локальные шрифты доступны.
- Нет горизонтальной прокрутки, критичных наложений и ошибок JavaScript.
- Мобильное меню открывается и закрывается, `aria-expanded` обновляется, Escape работает.
- Галерея открывает фотографию в диалоге; Escape закрывает его и возвращает фокус.
- Карта OpenStreetMap отображает тайлы и маркер на координатах 56.145343, 40.421006.
- Контакты ведут на подтверждённые телефон и Telegram.
- Проверен режим `prefers-reduced-motion`; декоративные анимации отключаются.
- `npm run build` собирает версию предпросмотра с `noindex`.

До коммерческой публикации нужно получить и заменить исходник чёрно-белой фотографии в полном разрешении, согласовать услуги/цены, точный адрес, часы работы, фотографии настоящих работ и конечный HTTPS-адрес для публичной SEO-сборки.
