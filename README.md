# HABIB BARBER

Двуязычный статический сайт барбера Хабиба во Владимире. Основой дизайна стал предоставленный владельцем архив `HABIB_BARBER_V1_demo.zip`: сохранены композиция, типографика, цвета, графические блоки и мобильная кнопка связи. Содержание обновлено по подтверждённым данным [Issue #1](https://github.com/artemshlyakov/barbersite/issues/1).

## Посмотреть локально

Сайт в корне репозитория готов к статическому просмотру без сборки и зависимостей:

```bash
python3 -m http.server 4173
```

Русская версия: `http://localhost:4173/`; английская: `http://localhost:4173/en/`.

Крупные кнопки связи открывают Telegram Хабиба или звонок. Собственной системы онлайн-записи нет. В блоке места показана карта на данных OpenStreetMap с подтверждённой точкой, без рекламного баннера. Карта собрана локальной копией Leaflet; подпись участников OpenStreetMap сохранена. Ссылка на маршрут в Яндекс Картах остаётся рядом с ориентиром у кафе «Юность».

## Индексация и публичная сборка

Корневые страницы предназначены для просмотра макета и содержат `noindex`. После выбора и утверждения коммерческого HTTPS адреса создайте публикационную сборку:

```bash
PUBLIC_SITE_URL=https://example.ru npm run build
```

Замените `example.ru` реальным доменом. Готовые файлы будут в `dist/`. В них включаются абсолютные canonical и hreflang ссылки, Open Graph URL и изображение, `sitemap.xml`, разрешающий `robots.txt`, а `noindex` удаляется. Если сайт размещается в подкаталоге, `PUBLIC_SITE_URL` должен включать этот путь; `robots.txt` для такого размещения нужно установить в корне хоста отдельно. Структурированные данные `BarberShop` содержат только подтверждённые телефон, город, координаты и ссылки. Точный адрес, часы и цены не указываются.

GitHub Pages можно использовать только для временного просмотра. Публичная сборка и коммерческий запуск требуют решения владельца о домене и хостинге.

## Что ещё ждём от владельца

- Подтверждённый список услуг и цены.
- Часы работы и точный почтовый адрес.
- Утверждённую биографию и текст о подходе.
- Фотографии реальных работ с правом публикации.
- Проверку финальной карты и текста на выбранном публичном домене.

Пока соответствующие блоки явно помечены как ожидающие подтверждения. Фото Хабиба в `assets/habib.webp` взято из предоставленного архива. Используемые шрифты Manrope и Oswald размещены локально; тексты лицензий SIL OFL находятся в `assets/fonts/`.

## Структура

- `index.html`, `en/index.html` — две индексируемые после публикации языковые страницы с общим дизайном.
- `styles.css`, `script.js` — оформление и мобильное меню.
- `assets/` — портрет, favicon, шрифты и Leaflet 1.9.4 с лицензией.
- `scripts/build.mjs` — сборка публикационной версии с адресами и sitemap.
- `docs/PROJECT.md`, `docs/QA.md` — факты проекта и результаты проверки.
