# HABIB BARBER

Демонстрационный сайт независимого барбера Хабиба во Владимире. Сейчас используется **восстановленный первоначальный дизайн**, который владелец проекта предпочёл альтернативному варианту: крупная контрастная типографика, тёмная палитра и тёплые бронзовые акценты.

## Просмотр
- Русская версия: https://artemshlyakov.github.io/barbersite/
- English: https://artemshlyakov.github.io/barbersite/en/

GitHub Pages — временная демонстрационная площадка. Обе версии закрыты от поисковой индексации (`noindex`).

## Технологии
Обычный HTML, CSS, JavaScript без сборки и сторонних npm-зависимостей. Публикация идёт из корня ветки `main`. Проверка CI находится в `.github/workflows/pages.yml`.

Основные файлы:
- `index.html`, `en/index.html` — страницы на русском и английском;
- `styles.css` — единые стили;
- `script.js` — мобильное меню;
- `public/images/habib-portrait.webp` — фотография;
- `public/favicon.svg` — favicon.

Для локального просмотра достаточно `python -m http.server 8080` из корня проекта.
