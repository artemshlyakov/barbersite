# HABIB BARBER — сайт барбера Хабиба

Двуязычный сайт барбера Хабиба во Владимире с онлайн-записью и закрытым кабинетом мастера. Основная версия публикуется из ветки `main` через GitHub Pages: https://artemshlyakov.github.io/barbersite/.

## Запуск сайта и CRM

Требуются Node.js 24.6 или новее, действующий серверный ключ TatNet к базе `habib_bd` и пароль мастера длиной от 16 символов. Зависимостей npm нет. В Bash можно ввести секреты без отображения:

```bash
read -rsp 'Ключ TatNet: ' TATNET_API_KEY; echo
read -rsp 'Пароль CRM: ' HABIB_ADMIN_PASSWORD; echo
export TATNET_API_KEY HABIB_ADMIN_PASSWORD
npm run build
npm start
```

Откройте [сайт](http://127.0.0.1:8080/), [английскую версию](http://127.0.0.1:8080/en/) и [CRM](http://127.0.0.1:8080/crm/). Кнопка в бежевом прайсе открывает календарь. Заявка занимает интервал сразу. Кабинет позволяет подтверждать и переносить записи, просматривать историю клиентов, менять услуги и управлять доступностью.

Обе версии сайта и кабинет используют один API. Запуск обращается к **реальной базе**. Для отдельной установки задайте UUID отдельной базы через `TATNET_DATABASE_ID` и примените к ней `supabase/migrations/001_booking.sql` один раз. В тестовой базе проекта эта миграция уже установлена.

## Размещение сервера

Сервер раздаёт только сборку из `dist/` и маршруты `/api/`. Укажите `PORT`, `HOST` и при необходимости абсолютный `STATIC_DIR`. Для Docker предусмотрен Dockerfile. Передайте секреты во время запуска. Для размещения используйте ключ только с правами чтения и SQL для нужной базы. Установите `APP_ORIGIN` в HTTPS-адрес и обеспечьте TLS на обратном прокси. Включайте `TRUST_PROXY=1` только за доверенным прокси, который перезаписывает адрес клиента и исключает прямое подключение к порту. Для одного мастера сервер работает в одном процессе. Сессии и ограничения по IP хранятся в памяти, поэтому перезапуск завершает сессии. Ограничение активных заявок по телефону проверяется в PostgreSQL.

Сайт и CRM проще разместить на одном домене. Если публичные страницы остаются на GitHub Pages, укажите HTTPS-origin сервера в `api-config.js` и задайте `ALLOWED_ORIGIN=https://artemshlyakov.github.io` серверу. CRM открывается на домене сервера. Статический хостинг сам по себе не исполняет API. В `api-config.js` хранятся только публичные настройки.

## Содержание

- Первый экран использует чёрно-белый кадр рабочего момента, присланный владельцем в диалоге. Так как исходный файл не был доступен в рабочем окружении, для макета сделана аккуратно увеличенная версия изображения; перед окончательной публикацией желательно заменить её исходником полного разрешения.
- Портрет и слова Хабиба размещены в блоке знакомства. Для компактного портрета `assets/habib-detail.webp` кадрирован предоставленный владельцем `assets/habib.webp`; факт «более 5 лет» подтверждён его текстом.
- Стартовые услуги: стрижка и борода по 1 000 ₽ и 30 минут, удлинённая стрижка 1 700 ₽ и 45 минут. Актуальный прайс загружается из базы.
- Галерея содержит 19 фотографий работ Хабиба, переданных владельцем. Порядок начинается с исходных файлов № 2, 15, 16, 19, 1; затем следуют остальные. На сайте файлы лежат в `assets/work/` с сохранёнными номерами. Под фотографиями нет подписей; галерея использует нативную горизонтальную прокрутку. Визуальный рельс с горизонтальной машинкой показывает положение в ленте; стрелки и перетаскивание машинки листают фотографии. Без JavaScript остаётся обычная полоса прокрутки. Названия конкретных стрижек не указаны, пока их не подтвердит мастер.
- Гирлянда в блоке прайса использует иконку `lightbulb-filament` из [Phosphor Icons](https://github.com/phosphor-icons/core) по лицензии MIT; текст лицензии сохранён в `assets/icons/PHOSPHOR-LICENSE.txt`.
- Ножницы, машинка и значки способов связи взяты из [Tabler Icons](https://github.com/tabler/tabler-icons) по лицензии MIT; текст лицензии сохранён в `assets/icons/TABLER-LICENSE.txt`.
- Телефон, Telegram, координаты и ориентир рядом с кафе «Юность» взяты из подтверждённых данных проекта. Карта использует изображение Yandex Static Maps с точкой на подтверждённых координатах; вся карта открывает интерактивные Яндекс.Карты в новой вкладке. На самом сайте нет рекламного блока, логотип и атрибуция Яндекса остаются видимыми. Текущий endpoint `1.x` работает без ключа, но относится к прежней версии API. Для долгосрочной стабильности следует получить ключ для актуального Static Maps API v1.

## SEO и публикация

GitHub Pages остаётся с `noindex`, пока демонстрационные услуги и цены не утверждены владельцем. После согласования окончательного содержания и коммерческого HTTPS-адреса `PUBLIC_SITE_URL=https://example.ru npm run build` создаст canonical, hreflang, sitemap, Open Graph URL и разрешающий `robots.txt`. Данные услуг и цен в JSON-LD отсутствуют, пока не подтверждены. Точный адрес и часы работы также ожидают подтверждения.
