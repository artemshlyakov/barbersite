# HABIB BARBER — концепция для просмотра

Двуязычный статический сайт персонального барбера Хабиба во Владимире. Эта ветка — новый визуальный вариант для обсуждения с владельцем; она не меняет опубликованный сайт.

## Локальный просмотр

```bash
python3 -m http.server 4173
```

Русская версия: `http://localhost:4173/`, английская: `http://localhost:4173/en/`. Для готовой папки предпросмотра выполните `npm run build`; результат появится в `dist/` с `noindex` и закрытым `robots.txt`.

## Содержание

- Первый экран использует чёрно-белый кадр рабочего момента, присланный владельцем в диалоге. Так как исходный файл не был доступен в рабочем окружении, для макета сделана аккуратно увеличенная версия изображения; перед окончательной публикацией желательно заменить её исходником полного разрешения.
- Портрет и слова Хабиба размещены в блоке знакомства. Факт «более 5 лет» подтверждён его текстом.
- Цены 1 000 ₽ / 700 ₽ / 1 700 ₽ даны владельцем как **демонстрационные** и прямо помечены на сайте. В структурированные данные они не добавлены.
- Два кадра Unsplash служат иллюстративными референсами и не представлены как работы Хабиба: [стрижка](https://images.unsplash.com/photo-1599351431202-1e0f0137899a), [борода](https://images.unsplash.com/photo-1503951914875-452162b0f3f1). Лицензия: Unsplash License.
- Телефон, Telegram, координаты и ориентир рядом с кафе «Юность» взяты из подтверждённых данных проекта. Карта работает на локальном Leaflet и тайлах OpenStreetMap с обязательной атрибуцией.

## SEO и публикация

Корневые HTML-страницы и обычная сборка закрыты от индексации. После утверждения дизайна и коммерческого HTTPS-адреса `PUBLIC_SITE_URL=https://example.ru npm run build` создаст canonical, hreflang, sitemap, Open Graph URL и разрешающий `robots.txt`. Данные услуг и цен в JSON-LD отсутствуют, пока не подтверждены. Точный адрес и часы работы также ожидают подтверждения.

Сайт не содержит формы, CRM или самостоятельной системы бронирования: запись ведёт в подтверждённый Telegram и на телефон. Файлы `index.html`, `en/index.html`, `styles.css`, `script.js` и `assets/` можно размещать на любом статическом хостинге. Зависимостей для работы сайта нет.
