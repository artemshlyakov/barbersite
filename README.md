# HABIB BARBER

Двуязычный статический сайт персонального барбера Хабиба во Владимире. Новая дизайн-версия развивает тему Heritage Barbershop: портрет мастера как главный визуальный актив, крупная типографика, тёплая латунь, тёмные поверхности и один светлый редакционный разворот для услуг. Сравнение с предыдущей версией — в [дизайн-ревью](docs/design-review.md).

## Локальный просмотр

Сборка и установка зависимостей для просмотра не требуются:

```bash
python3 -m http.server 4173
```

RU: `http://localhost:4173/`; EN: `http://localhost:4173/en/`.

Кнопки записи открывают [Telegram Хабиба](https://t.me/khabiBarber), телефон — `tel:+79040339177`. Галерея имеет просмотр фотографий крупным планом; сейчас там **иллюстративные референсы, не работы Хабиба**. Источники: [референс стрижки](https://images.unsplash.com/photo-1599351431202-1e0f0137899a), [референс ухода за бородой](https://images.unsplash.com/photo-1503951914875-452162b0f3f1), Unsplash License. Портрет Хабиба предоставлен владельцем.

Секция услуг показывает **демонстрационный макет прайса**: названия позиций служат примером интерфейса, а состав, длительность и стоимость явно помечены как уточняемые. Реальные данные нужно согласовать до коммерческой публикации.

## Карта и контакты

Точка на карте OpenStreetMap соответствует координатам 56.145343, 40.421006; вход рядом с кафе «Юность». Локальная копия Leaflet не загружает код с внешнего CDN, но тайлы карты требуют доступа к OpenStreetMap. Есть ссылки на полную карту и маршрут в Яндекс Картах. Часы и точный почтовый адрес не подтверждены.

## SEO и публикация

По умолчанию RU/EN страницы содержат `noindex`, а `robots.txt` запрещает обход. Это версия для просмотра. После утверждения домена и данных публичную сборку создают так:

```bash
PUBLIC_SITE_URL=https://example.ru npm run build
```

Замените `example.ru` настоящим HTTPS-доменом. В `dist/` появятся canonical, hreflang, Open Graph URL, `sitemap.xml` и разрешающий `robots.txt`; `noindex` удалится. Структурированные данные `BarberShop` содержат только подтверждённые контакты, город и координаты. Если сайт размещается в подкаталоге, `PUBLIC_SITE_URL` должен включать этот путь; `robots.txt` для него нужно разместить в корне хоста отдельно.

GitHub Pages остаётся временным клиентским просмотром. Коммерческий запуск требует решения владельца о домене, хостинге и содержимом.

## Структура

- `index.html`, `en/index.html` — страницы RU/EN.
- `styles.css`, `script.js` — общая дизайн-система, меню, галерея и карта.
- `assets/` — портрет, референсы, шрифты (SIL OFL), favicon, локальная копия Leaflet с лицензией.
- `scripts/build.mjs` — сборка превью или публичной версии.
- `docs/PROJECT.md`, `docs/QA.md`, `docs/design-review.md` — факты, проверки и визуальное сравнение.
