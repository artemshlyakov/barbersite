# HABIB BARBER

Статический двуязычный сайт независимого барбера Хабиба во Владимире. Версия V1 знакомит с мастером, показывает подтверждённые контакты и ориентир, даёт связаться для согласования визита. Онлайн-записи и клиентской базы нет.

## Локальный просмотр

Требуется Node.js 20.11+ (или 22+). Зависимостей нет.

```bash
npm run build
python3 -m http.server 4173 -d dist
```

Откройте `http://localhost:4173/` и `http://localhost:4173/en/`. Сборка по умолчанию создаёт демонстрационный вариант с `noindex` и запретом индексации в `robots.txt`.

## Публикация после согласования

На утверждённом публичном домене задайте полный HTTPS адрес сайта без завершающего `/`:

```bash
PUBLIC_SITE_URL=https://example.ru npm run build
```

В этой сборке создаются абсолютные canonical и hreflang ссылки, Open Graph URL, `sitemap.xml` и разрешающий `robots.txt`. Вместо `example.ru` должен быть реальный утверждённый домен. Файлы из `dist/` можно разместить на любом статическом хостинге с сохранением структуры каталогов. GitHub Pages допустим только как временный просмотр; публичный коммерческий адрес и хостинг ещё выбираются.

## Содержание и исходники

- `scripts/build.mjs` — общая структура страниц, тексты RU/EN и метаданные.
- `public/assets/site.css` — адаптивный дизайн; `site.js` закрывает мобильное меню после выбора раздела.
- `public/images/habib-portrait.webp` — портрет, предоставленный владельцем.
- `public/favicon.svg` — знак HB.

Услуги и цены, часы работы, согласованная биография, фотографии работ и полный адрес ожидают подтверждения владельца. Пока сайт прямо сообщает об этом. Координаты и ориентир взяты из [Issue #1](https://github.com/artemshlyakov/barbersite/issues/1); перед визитом посетителю предложено уточнить маршрут.
